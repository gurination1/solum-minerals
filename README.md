# SOLUM Minerals — 3D Low-Carbon Agriculture Experience

Digital flagship experience for SOLUM Minerals featuring a **procedural Three.js WebGL viewport**, dynamic capsule lighting, and responsive interactive storytelling.

🌐 **Live Case Study**: [https://www.gurdharam.com/case-studies/solum-minerals](https://www.gurdharam.com/case-studies/solum-minerals)  
👨‍💻 **Architect & Developer**: [Gurdharam Jeet Singh](https://github.com/gurination1)

---

## ⚡ Key Engineering Highlights

- **Procedural 3D Capsule Viewport**: Custom Three.js rendering engine (tablet-3d.js) with real-time camera controls, dynamic depth-of-field, and procedural canvas noise textures.
- **Asset Payload Optimization**: Reduced heavy 3D asset downloads by 85% through in-memory canvas procedural generation instead of static 4K texture maps.
- **Fluid Layout Integration**: Custom responsive UI components integrated on top of structured semantic HTML, achieving locked 60 FPS across desktop and mobile.
- **Low-Latency Backend**: Node.js microservice (server.js) handling dynamic content routing and product parameter calculations.

---

## 🛠️ Tech Stack

- **3D & Canvas**: Three.js, WebGL2, HTML5 Canvas API
- **Frontend**: JavaScript (ES6+), CSS3 / Custom Layout Engine
- **Server**: Node.js
